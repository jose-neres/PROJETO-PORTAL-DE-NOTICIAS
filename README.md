# 📰 Portal de Notícias

<div align="center">

Aplicação web desenvolvida para apresentação e organização de conteúdos jornalísticos através de uma interface moderna e estruturada.

</div>

---

## 📌 Sobre o Projeto

O **Portal de Notícias** é um projeto Front-End criado com o objetivo de desenvolver uma página inspirada em plataformas de notícias, explorando conceitos de estruturação de conteúdo, hierarquia visual e construção de interfaces web.

A aplicação apresenta uma organização de informações baseada em um portal jornalístico, com áreas destinadas a notícias em destaque, categorias e conteúdos informativos, proporcionando uma experiência visual clara e objetiva ao usuário.

Este projeto faz parte da evolução prática em desenvolvimento web, aplicando conceitos fundamentais de **HTML e CSS na criação de interfaces.

## 🎯 Objetivos do Projeto

Durante o desenvolvimento foram aplicados conhecimentos como:

* Estruturação de páginas web utilizando HTML semântico
* Criação de layouts e componentes visuais com CSS
* Organização de informações em uma interface de notícias
* Manipulação de elementos utilizando JavaScript
* Prática de desenvolvimento Front-End

## ✨ Características

✔ Organização de conteúdos por seções
✔ Destaque visual para informações principais

## ▶️ Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/jose-neres/PROJETO-PORTAL-DE-NOTICIAS.git
```

Entre na pasta do projeto:

```bash
cd PROJETO-PORTAL-DE-NOTICIAS
```

Execute abrindo o arquivo:

```bash
index.html
```

no navegador.
